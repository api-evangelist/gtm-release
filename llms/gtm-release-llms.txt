# GTM Release

> An API Evangelist network index of the 55 companies, platforms, and events that make up a go-to-market release surface — press and tech media, developer communities, open-source and developer-tool directories, social, podcasts, business and startup directories, product-launch and SaaS platforms, review platforms, and conferences.

GTM Release is not a company and does not operate an API. It is a curated index maintained by API Evangelist that groups existing provider profiles in the api-evangelist network by the role each plays in launching and distributing software. Every entry below is a separately profiled provider with its own apis.yml, artifacts, and Kin Score. Use this file to walk the launch surface; use each provider profile for that provider's actual API.
